# Studio AS Bio Link

Site simples de bio link para Studio AS.

## Conteúdo

- `index.html` — página principal com perfil e serviços
- `logo.jpg` — imagem do logo usada no avatar e no background

## Uso

1. Abra `index.html` em um navegador.
2. Altere o conteúdo diretamente no HTML, se necessário.

## Notas

- A página usa Tailwind CSS via CDN.
- O arquivo `logo.jpg` é referenciado localmente.
